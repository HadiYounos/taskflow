Built from scratch, built to be used

TaskFlow is a front-end portfolio project that behaves like a real product. It is written with plain HTML, CSS and JavaScript, organized into small modules, and designed to be fast, accessible and easy to read.

Open the dashboard

  • No frameworks

    Vanilla HTML5, CSS3 and JavaScript ES6+.

  • Accessible

    Semantic markup, keyboard support and visible focus.

  • Fast

    Event delegation and targeted rendering keep it light.

  • Private

    Your tasks never leave your browser.
